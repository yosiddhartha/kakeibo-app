# 複式簿記家計簿アプリケーション (Double-Entry Kakeibo App)

※このアプリはgeminiを利用したバイブコーディングによって作成しました。
Python (PyQt) と SQLite を用いて構築した、個人向けのデスクトップ型・複式簿記家計簿アプリケーションです。
単式の家計簿とは異なり、借方・貸方の概念を取り入れることで、資産や負債の正確な増減管理と財務諸表の確認を可能にしています。

## 🛠️ 主な機能
- **複式仕訳入力:** 借方・貸方の勘定科目を選択した仕訳の登録・管理
- **総勘定元帳:** 各勘定科目ごとの取引履歴の一覧表示
- **貸借対照表 (B/S) & 損益計算書 (P/L) の出力:** 資産・負債・収益・費用の自動集計
- **クレジットカード明細管理:** 毎月の明細と利用金額を照合・確認可能
- **固定資産の管理:** 固定資産と耐用年数を登録し、毎月の減価償却費の計上はボタン一つで実行
- **収支推移グラフ:** Matplotlibを用いた収支推移のグラフ化

## 💻 技術スタック
- **言語:** Python
- **GUIフレームワーク:** PyQt
- **データベース:** SQLite3
- **データ処理・可視化:** pandas, matplotlib
